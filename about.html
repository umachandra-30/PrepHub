About PrepHub

PrepHub is a premium, lightweight placement preparation portal built to assist engineering students and job aspirants in cracking technical rounds, quantitative assessments, logical tests, and verbal screenings. By providing structure, detailed explanations, timed test environments, and client-side performance logs, PrepHub helps users build competence and confidence without login blocks or intrusive advertisements.

Core Platform Features

2000+ Question Bank

Dynamically loaded questions curated across 30 distinct subjects, tracking specific companies and tags.

Timed Mock Assessments

Generate randomized test packages of 10, 25, or 50 questions with customized category filters and running timers.

Intelligent Bookmarks

Save tricky challenges to your personal boards. Test yourself directly on bookmarks using inline evaluation utilities.

Performance Analytics

Track completion levels and choice accuracy percentages per category and subject, saved securely in your browser.

Technology Stack

PrepHub is engineered to run fully static, prioritizing speed, accessibility, and simplicity. The frontend codebase relies entirely on vanilla web technologies:

HTML5 Semantic layouts, accessibility tags, and dynamic iframe-free DOM rendering structures.
Vanilla CSS3 Flexible layouts via CSS Grid and Flexbox, custom design properties, keyframe skeletons, and responsive media query blocks.
Vanilla JS (ES6) Fetch API operations, asynchronous promises, modular page state listeners, and dynamic browser layout injection structures.
LocalStorage Local user storage parsing to keep bookmarks list, solved stats, and recently viewed logs persistent without servers.
